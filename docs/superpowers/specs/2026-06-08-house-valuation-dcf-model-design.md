# 房产估值 DCF 模型设计

## 概述

用现金流贴现法（DCF）对自住房产进行估值，采用实际值（Real Terms）框架。模型包含两大模块：公允价值分析和 NPV 决策分析，配合敏感性分析。

## 输入参数

### 固定参数（购房方案）

| 参数 | 值 |
|---|---|
| 总房价 (P) | 1,500,000 元 |
| 首付比例 | 20% |
| 首付金额 | 300,000 元 |
| 贷款金额 | 1,200,000 元 |
| 贷款年限 | 30 年（360 期） |
| 贷款利率 | 2.6%（年） |
| 还款方式 | 等额本息 |

### 估值假设

| 参数 | 值 |
|---|---|
| 持有期 | 30 年 |
| 同户型月租金 | 3,000 元 |
| 年持有成本 | 3,000 元（≈1个月租金） |
| 租金/成本实际增长率 | 1.5%/年 |
| 通胀率 | 1.0%/年 |
| 折现率（实际） | 4.0% |
| 期末残值（实际，不折现） | 500,000 元 |

## 模型框架

### 月供计算

等额本息公式：

```
月供 = 贷款金额 × r × (1+r)^n / ((1+r)^n - 1)

其中：
r = 2.6% / 12 = 0.2167%（月利率）
n = 360 期
```

### 模块一：公允价值分析

**目的：** 计算房产的居住使用价值，不涉及贷款结构。

逐年现金流（实际值，t = 1 到 30）：

```
省租金(t) = 36,000 × (1.015)^(t-1)
持有成本(t) = 3,000 × (1.015)^(t-1)
净现金流(t) = 省租金(t) - 持有成本(t)
```

**公允价值 = Σ [净现金流(t) / (1.04)^t] + 500,000**

### 模块二：NPV 决策模型

**目的：** 比较"买房"与"租房+投资"的财务优劣。

逐年现金流：

```
t = 0：CF = -300,000（首付）

t = 1 到 30：
省租金(t) = 36,000 × (1.015)^(t-1)         // 实际值
持有成本(t) = 3,000 × (1.015)^(t-1)        // 实际值
月供实际值(t) = 57,648 / (1.01)^(t-1)       // 名义月供按通胀率转为实际值
净现金流(t) = 省租金(t) - 持有成本(t) - 月供实际值(t)

t = 30（额外）：+500,000                    // 期末残值，不折现
```

**NPV = -300,000 + Σ[净现金流(t) / (1.04)^t] + 500,000**

### 模块三：敏感性分析

二维矩阵，观察 NPV 变化：

| 维度 | 取值 |
|---|---|
| 折现率 | 3.0%、4.0%、5.0% |
| 租金/成本增长率 | 0.0%、1.5%、3.0% |

额外输出：盈亏平衡房价（NPV = 0 时的房价）

## 关键解读规则

| 指标 | 含义 |
|---|---|
| 公允价值 > 150万 | 居住价值超过售价，值得买 |
| 公允价值 < 150万 | 居住价值低于售价，溢价来自市场因素 |
| NPV > 0 | 买房比租房+投资划算 |
| NPV < 0 | 租房+投资更划算 |

## 可视化输出

1. 逐年现金流柱状图（展示每年的现金流入/流出结构）
2. 累积 NPV 曲线（展示随时间推移，NPV 如何变化）
3. 敏感性分析热力图
4. 盈亏平衡散点图

### 参数设计原则

所有参数集中在 Notebook 首个 Cell 的变量区，修改后从头运行即可刷新全部输出。用户可任意调整：
- 房价、首付比例、贷款利率/年限
- 月租金、持有成本
- 增长率、通胀率、折现率
- 期末残值、持有周期

无需修改代码逻辑，改参数即可。
