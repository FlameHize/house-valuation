# 房产估值特征价格调价模型设计

## 概述

在 DCF 模型计算出小区居住公允价值的基础上，通过特征价格法（Hedonic Pricing Model）对具体房源进行调价，最终得到针对特定房源的个性化估值。

**定位：** DCF 模型回答"这个小区基准值多少"，调价模型回答"同一小区内这套具体房源怎么定价"。

## 输入

### 基准价

用户手动输入，通常取 DCF 模型输出的公允价值（如 1,354,580 元）。

### 特征参数

| 参数 | 输入方式 | 说明 |
|---|---|---|
| 楼层 | 数字 | 具体楼层号 |
| 总层数 | 数字 | 楼栋总层数 |
| 房龄 | 数字 | 楼龄（年） |
| 朝向 | 选择 | 南 / 东南 / 东 / 西 / 北 |
| 学区 | 选择 | 重点 / 普通 / 无 |
| 地铁距离 | 数字 | 距最近地铁站距离（米） |
| 物业品质 | 选择 | 优质 / 普通 / 老旧 |
| 装修 | 选择 | 精装 / 简装 / 毛坯 |
| 商业配套 | 选择 | 成熟 / 一般 / 匮乏 |
| 容积率 | 数字 | 小区容积率（如 2.5） |
| 绿化率 | 数字 | 小区绿化率百分比（如 30） |

## 模型

### 公式

```
最终估值 = 基准价 × (1 + r_楼层) × (1 + r_房龄) × (1 + r_朝向) × (1 + r_学区)
                × (1 + r_地铁) × (1 + r_物业) × (1 + r_装修) × (1 + r_商业)
                × (1 + r_容积率) × (1 + r_绿化率)
```

乘法模型，各因子独立，调整率为百分比。

### 系数表

数据来源：银行抵押评估惯例 + 公开学术研究 + 行业通行标准。

#### 楼层（按相对位置，有电梯高层）

| 条件 | 调整率 |
|---|---|
| 底层（1 层或设备层） | -5% ~ -8% |
| 中低层（1/4 高度以下） | -2% |
| 中间层（1/4 ~ 3/4 高度） | +3% ~ +5% |
| 高层（3/4 高度以上，非顶层） | +1% |
| 顶层 | -3% ~ -5% |

#### 房龄

| 条件 | 调整率 |
|---|---|
| 每年 | -0.5% |
| 上限 | -25%（20 年后折价递减至不再显著） |

#### 朝向

| 朝向 | 调整率 |
|---|---|
| 南 | 0% |
| 东南 | -1% |
| 东 | -2% |
| 西 | -2% |
| 北 | -2.5% |

#### 学区

| 等级 | 调整率 |
|---|---|
| 重点学区 | +10% |
| 普通学区 | +3% |
| 无学区 | 0% |

#### 地铁

| 距离 | 调整率 |
|---|---|
| ≤ 300m | +20% |
| ≤ 500m | +12% |
| ≤ 1000m | +5% |
| > 1000m | 0%（不折价） |

#### 物业品质

| 等级 | 调整率 |
|---|---|
| 优质 | +5% |
| 普通 | 0% |
| 老旧 | -3% |

#### 装修

| 等级 | 调整率 |
|---|---|
| 精装 | +5% |
| 简装 | +2% |
| 毛坯 | 0% |

#### 商业配套

| 等级 | 调整率 |
|---|---|
| 成熟 | +3% |
| 一般 | 0% |
| 匮乏 | -2% |

#### 容积率

| 条件 | 调整率 |
|---|---|
| < 2.0（低密舒适） | +3% |
| 2.0 ~ 3.5（普通） | 0% |
| > 3.5（高密拥挤） | -3% |

#### 绿化率

| 条件 | 调整率 |
|---|---|
| > 35%（高绿化） | +3% |
| 20% ~ 35%（普通） | 0% |
| < 20%（低绿化） | -3% |

## Notebook 结构

文件：`house_valuation_hedonic.ipynb`

| 章节 | 内容 |
|---|---|
| 一、输入参数 | 基准价 + 所有特征输入 |
| 二、系数明细 | 展示当前各特征调率，可手动覆盖 |
| 三、单一房源估值 | 逐项调整展示 + 最终估值 |
| 四、批量对比 | 输入多个房源 → 输出对比表（售价/调后估值/价差/排序） |
| 五、可视化 | 瀑布图（各因子贡献），多房源对比柱状图 |
| 六、生成报告 | Markdown + PNG 输出 |

## 输出

- 单一房源：基准价 → 各因子调整金额 → 最终估值
- 批量对比：多套房源并列，含售价、估值、价差、推荐排序
- 报告：保存到 `reports/` 目录

## 参数设计原则

所有参数集中在首个 Cell，系数表集中管理。用户可任意调整系数值，无需修改代码逻辑。
